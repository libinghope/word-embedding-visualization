# 已知限制

- MVP 只在当前 1,000 词内精确检索，不能用结果代替全模型最近邻。真实构建严格要求 1,000×300；任意维度的外部模型导入属于后续工作。
- 静态向量无法区分 apple 的水果/公司等不同语境，历史新闻模型也可能反映语料偏差。
- PCA 和 UMAP 的轴、全局间距不具备固定语义含义；局部可信度只是一个诊断，不证明无损。
- 复现要求固定输入、依赖与环境。UMAP/线性代数跨平台不保证逐位一致。小于等于 4 个点的测试构建使用 UMAP random 初始化，较小集合自动缩小 n_neighbors；真实 1,000 词不使用这些例外。
- Google News 的再分发许可尚未明确；fastText 对齐模型来源清单记录 CC-BY-SA-3.0。当前仅本地预览，公开发布需按各来源分别处理许可与归属。
- 无 WebGL 时会显示错误；搜索和数学面板仍可使用。小屏使用分栏切换，词语模式显示选中、悬停及周边词，连接模式优先显示领域输入、定位词和前 5 个桥梁候选；标签自动避让，完整结果始终可在列表查看。
- 构建报告的峰值内存字段若为 null 表示尚未测量，不据此声称内存基准达标。
- 当前无账号、数据库、在线模型上传、生产权限管理及全模型 ANN 检索；本地服务绑定 127.0.0.1。
